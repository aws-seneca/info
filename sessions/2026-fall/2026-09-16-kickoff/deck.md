## Slide 7. Five services you'll hear everywhere

On screen:

```
Five services you'll hear everywhere.
EC2
Virtual servers, computing power you can spin up and shut down
S3
File storage, store anything and access it anywhere
IAM
Identity and access, who's allowed to do what
RDS
Managed databases without the server admin work
Lambda
Run code without managing a server at all
```

Notes: There are over 200 AWS services. Most engineers spend 90% of their time in fewer than ten. These five show up in almost every architecture and every job posting.Go through each in thirty seconds or less. The goal is familiarity, not comprehension, so it clicks when they hear it again at Event 2. (~4 min)
